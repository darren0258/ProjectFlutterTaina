# แปลเกม (Game Translator)

แอป Android แปลบทพูด/ซับเกมภาษาอังกฤษเป็นไทยแบบอัตโนมัติ ไม่ต้องกด

- **โหมดฟังเสียง**: ฟังเสียงจากลำโพงทีวีต่อเนื่อง แปลทุกประโยค (เห็นคำแปลระหว่างพูดด้วย)
- **โหมดกล้อง**: เล็งกล้องไปที่ทีวี อ่านซับในกรอบสีเหลืองทุก ~0.4 วินาที แปลเมื่อข้อความเปลี่ยน
  เก็บประวัติย้อนหลัง และเลือกให้อ่านออกเสียงภาษาไทยได้

การอ่านตัวอักษรและการแปลใช้ Google ML Kit ทำงานในเครื่อง (offline) หลังโหลดชุดภาษาครั้งแรก

## ติดตั้ง
ไปที่หน้า **Releases** ของ repo นี้ด้วยมือถือ → โหลด `game-translator.apk` → กดติดตั้ง
(APK สร้างอัตโนมัติโดย GitHub Actions ทุกครั้งที่แก้โค้ดในโฟลเดอร์นี้)
